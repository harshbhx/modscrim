Mod docs. You moderate a channel that runs drills and want to know what you will see and do. Not what you came for? Find the right docs.

1. Open the mod link

Your streamer shares a link that ends in /mod/ and their channel name.

2. Enter the code and a name

Type the 6-digit code and the name you want on the scoreboard, then press Join.

3. Wait for the whistle

“You’re in. Remove attacks, leave regulars alone.” You’ll see who else has joined.

If the code doesn’t work

  • Codes are random for every drill and stop working when the drill ends. Ask your streamer for the current one.
  • “There is no open drill yet. Ask the streamer to start one.” means the streamer hasn’t opened a drill.
  • “Too many join attempts. Try again in a minute.” Codes are rate-limited against guessing.
  • “Your session ended. Enter the code to join again.” Your join lasts a limited time in your browser; enter the code again.

You need a current browser (Chrome, Edge, Firefox or Safari) and a screen at least 360 pixels wide.
