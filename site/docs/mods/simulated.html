Mod docs. You moderate a channel that runs drills and want to know what you will see and do. Not what you came for? Find the right docs.

What is simulated

  • The attacks. Every attack line is generated. Every link ends in .invalid, so it can’t open. Slurs, if the streamer turns that tactic on, are placeholders drawn as solid blocks.
  • The banter. The harmless lines come from a curated pool, never from real viewers’ messages.
  • Kai (sim). A simulated co-mod for rehearsing alone. It acts on about 60% of attacks after a few seconds and sometimes on tempting banter, so you can see a false ban happen. It is always labelled “(sim)” and scored separately.
  • The demo room. If you are in a demo room, the channel and its chat log are sample data and its grades are a labelled local estimate.

What you never touch

  • Nothing is posted to the real chat. The only message ModScrim can ever send is an optional fixed line when a drill starts, and it never contains attack text.
  • Delete, Timeout and Ban only score the drill. Nobody real is removed from anything.
  • You never see your streamer’s chat log, tokens or blocked terms.
  • Viewers see an overlay where every attack message is a blurred bar. They never learn a working trick.

The full list is on the safety page.
